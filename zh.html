常见问题

常见问题解答

为大家最常问的问题提供简短回答。

如何在线压缩图片？

把图片添加到上方的图片压缩工具，选择 WebP 或 JPEG，质量保持在 80% 左右，需要时设置最大宽度，然后下载更小的文件。全部在浏览器中完成，不会上传任何内容。

这个图片压缩工具真的免费吗？

是的。无需注册、没有水印、没有每日额度。唯一的限制是你自己设备的内存，因为处理都在设备上进行。

我的图片会被上传到服务器吗？

不会。压缩在你的浏览器中通过 canvas API 完成，图片不会离开你的设备。只有在使用这两项功能时才会加载两个辅助脚本（创建 ZIP 和转换 HEIC），而 AVIF 使用的是由本站提供的编码器。

图片能缩小多少？

取决于图片本身。大尺寸相机照片以约 80% 质量保存为 WebP 时，体积通常缩小 50% 到 80%。本来就已经优化过的文件（例如小徽标）可能几乎没有变化。

应该选择哪种输出格式？

WebP 是网页的最佳默认选择。需要最广泛的兼容性时选 JPEG，需要无损输出或透明度时选 PNG，想要最小的文件且你的用户使用现代浏览器时选 AVIF。

压缩会降低图片质量吗？

JPEG、WebP 和 AVIF 都是有损格式，会舍弃一些细节。在 70% 到 85% 之间，差异通常肉眼很难察觉。拖动滑块、对比结果，保留你满意的最低设置即可。

会删除 GPS 位置等 EXIF 数据吗？

会。通过 canvas 重新编码会丢弃包括相机信息和 GPS 坐标在内的元数据。图片的旋转方向会先被应用，所以看起来依然是正的。

为什么我的 PNG 几乎没有变小？

PNG 是无损格式，没有可调低的质量设置。想要更大幅度的缩减，请把输出改为 WebP 或 JPEG，或者减小最大宽度。
