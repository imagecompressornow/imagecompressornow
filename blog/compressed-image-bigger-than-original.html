Why Is My Compressed Image Bigger Than the Original? 7 Causes and Fixes

It feels impossible, but it happens all the time. Here is what is really going on and how to get a smaller file.

By the ImageCompressorNow team · Published 2026-11-12 · 6 min read

You drop a photo into a compressor, wait a second, and the "compressed" file is larger than the one you started with. That is not a bug in your browser. It is a consequence of how image formats work. Below are the seven most common causes, ordered from most to least likely.

1. The original was already highly optimized

A file exported from a professional tool, a good CMS or a previous compressor has little fat left to trim. Re-encoding it at a quality setting higher than the one used originally produces a bigger file with no visible gain. Fix: lower the quality a little, or accept that the file is already efficient. Our compressor returns the original when a same-format re-encode would only make it bigger.

2. Quality is set too high

Quality 100% in JPEG or WebP is not "lossless". It is a very expensive lossy setting that can double the size compared with 85%. Many cameras and phones save at a moderate level, so pushing to 100% inflates the file. Fix: use 75 to 85% for photos.

3. You converted a photo to PNG

PNG stores every pixel exactly. For photographs, with their gradients and noise, that is extremely wasteful, and a PNG copy of a JPEG is often several times bigger. Fix: keep photos as JPEG, WebP or AVIF. Use PNG only for logos, icons and screenshots with flat colors.

4. A screenshot or graphic was converted to JPEG at high quality

The reverse problem. JPEG struggles with sharp edges and text, so to avoid ugly fringes it needs a high quality value, and the file balloons. Fix: save text-heavy graphics as PNG or WebP instead.

5. The image was enlarged

If a small image is scaled up, the file has more pixels to describe even though no new detail exists. Fix: never upscale. In our tool the width setting only shrinks images, it never enlarges them.

6. Heavy grain or noise

Night photos, film grain and high-ISO shots are full of random pixel variation, which compression cannot predict. They compress badly in every format. Fix: reduce the dimensions, or lower quality further than you would for a clean daylight photo.

7. A transparent image went into a format without transparency

When a PNG with a see-through background is converted to JPEG, the transparent area is filled with a solid color. That is expected, and the size result depends on what is underneath. Fix: keep transparency by choosing WebP or PNG as the output.

Does removing metadata make a file bigger?

No. Metadata such as camera details and GPS data is usually small, and stripping it only makes the file lighter. When a result is bigger, the cause is nearly always one of the seven above.

Try the fixes in order

  1. Open the image compressor and add the file.
  2. Choose WebP, or JPEG if you need maximum compatibility.
  3. Set quality to about 80%.
  4. If it is still large, set a maximum width that suits where the image will be used.

Quick answers

Why did my PNG get bigger after compression?

PNG is lossless, so re-encoding it rarely saves much and can add a few bytes. Switch the output to WebP or JPEG for photos, or reduce the width.

Is a 100% quality setting lossless?

No. In JPEG and WebP it is still lossy, just very conservative, and it often produces a file much larger than 85 percent quality with almost no visible difference.

Can compressing twice make the image worse?

Yes. Each lossy pass discards more detail. Always return to the original file when you adjust settings instead of recompressing the output.

What should I do when a file will not get any smaller?

Lower the maximum width. Reducing pixel count is the strongest way to cut size when quality changes stop helping.
