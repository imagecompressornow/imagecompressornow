为什么压缩后的图片比原图还大？7 个原因与解决办法

这听起来不可能，却时常发生。下面讲讲真正的原因，以及如何得到更小的文件。

Image Compressor Now 团队发布于 2026-11-12更新于 2026-11-13阅读约 7 分钟
简短回答

当图片被重新编码的效率低于原图时，压缩后就会变大：质量设置过高、把照片存成 PNG、对已优化的文件重新编码，或者图片被放大。对于照片，请使用 75% 到 85% 质量的 WebP 或 JPEG，把 PNG 留给纯色图形，并限制宽度。如果都没用，就保留原文件。

你把照片拖进压缩工具，等了一秒，结果“压缩后”的文件反而比原来的还大。这不是浏览器的问题，而是图片格式的工作方式造成的。下面按可能性从高到低列出 7 个最常见的原因，随后给出一个快速诊断自己文件的方法。

1. 原图本来就已经高度优化

从专业工具、优秀的 CMS 或之前的压缩工具导出的文件，已经没有多少可削减的空间。以高于原保存质量的设置重新编码，只会得到更大的文件，却没有任何可见的收益。解决办法：稍微降低质量，或者接受这个文件本来就已经很高效。当以相同格式重新编码只会让文件更大时，我们的压缩工具会把原文件还给你。

2. 质量设置得太高

JPEG 或 WebP 的 100% 质量并不是“无损”。那是一个代价极高的有损设置，可能让文件比 85% 时大得多，却几乎没有可见的好处。许多手机以中等质量保存，所以拉到 100% 反而会让文件膨胀。解决办法：照片使用 75% 到 85%。

3. 你把照片转换成了 PNG

PNG 会精确保存每一个像素。对于带有渐变和噪点的照片，这很浪费，把 JPEG 转成 PNG 往往会大好几倍。而且也没有什么可调整的：正如 MDN 所记载，浏览器只会把质量值用于 JPEG 和 WebP 这类有损格式。解决办法：照片保持为 JPEG、WebP 或 AVIF。PNG 用于标志、图标和纯色截图。

4. 截图或图形被以高质量转换成了 JPEG

这是相反的问题。JPEG 不擅长处理锐利的边缘和文字，为了避免难看的杂边，需要很高的质量值，文件因此膨胀。解决办法：文字较多的图形请保存为 PNG 或 WebP。

5. 图片被放大了

如果小图被放大，文件需要描述更多像素，尽管并没有新增任何细节。解决办法：永远不要放大。在我们的工具中，宽度设置只会缩小图片，不会放大。

6. 噪点或颗粒很多

夜景照片、胶片颗粒和高 ISO 拍摄的照片充满随机的像素变化，压缩算法无法预测。它们在任何格式下都难以压缩。解决办法：缩小尺寸，或者把质量降得比处理干净的白天照片更低。

7. 转成 WebP 或 AVIF 并没有带来好处

WebP 通常更小。Google 的研究测得，在相同视觉质量下，有损 WebP 比 JPEG 小 25% 到 34%，无损 WebP 比 PNG 小约 26%。这些是相对于标准编码器的平均值。面对已经调得很好的 JPEG，或者面对小型的调色板 PNG，差距可能缩小甚至反转。解决办法：把结果与原图对比，保留更小的那个。

删除元数据会让文件变大吗？

不会。相机信息和 GPS 数据之类的元数据通常很小，删除它们只会让文件更轻。当结果变大时，原因几乎总是上面七种之一。

按顺序尝试这些办法

  1. 打开图片压缩工具并添加文件。
  2. 选择 WebP；如果需要最大兼容性，则选 JPEG。
  3. 把质量设为约 80%。
  4. 如果仍然很大，请根据图片的使用位置设置合适的最大宽度。

快速解答

为什么我的 PNG 压缩后反而变大了？

PNG 是无损格式，重新编码很少能省多少，反而可能多出几个字节。对于照片，请把输出改为 WebP 或 JPEG，或者缩小宽度。

100% 的质量设置是无损的吗？

不是。在 JPEG 和 WebP 中它仍然是有损的，只是非常保守，而且往往比 85% 的质量大得多，几乎没有可见的区别。

转换成 WebP 一定会让文件更小吗？

照片通常如此，但不一定。小图、已经优化过的文件以及某些调色板 PNG，转成 WebP 后可能反而更大。请把结果与原图对比，保留更小的那个。

压缩两次会让图片更差吗？

会。每一次有损处理都会丢掉更多细节。调整设置时，请始终回到原始文件，而不是对输出结果再次压缩。

文件怎么都缩不小该怎么办？

减小最大宽度。当调整质量不再有效时，减少像素数量是最有力的缩小办法。
